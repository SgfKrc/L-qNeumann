# 权重熵：为什么训练权重压不下去，编译权重能压 654 倍

> 状态：**现行**
> 更新日期：2026-11-24
>
> 适用范围：权重可压缩性的边界——三种熵、存储代价的定义、以及由它推出的架构划界判据；读者为决定「这部分该训练还是该编译」的人。
> 相关：实测 [BASELINES](../measure/BASELINES.md)、里程碑 [MILESTONES](../measure/MILESTONES.md)、立场 [确定性分层](../insight/DETERMINISM.md)、立项 [PROPOSAL](../design/PROPOSAL.md)。

---

> 这一页回答一件事：**一个权重该占多少存储，是它「怎么来的」决定的，不是它「有多少个」决定的。**

## 一、一句话

**权重的存储代价 ≈ 还原它所需的那个程序的复杂度。**

| 权重怎么来的 | 还原它需要什么 | 存储代价 |
|---|---|---|
| 由确定性程序生成 | 那个程序（KB 量级） | **KB 量级**，可以无损压 3 个数量级 |
| 由训练得到 | 不存在这样的程序 | **= 它的信息量**，压不下去；任何压缩都有损 |

## 二、三种熵

「权重熵高」这个说法太粗，实际上有三种互相独立的熵，**它们可以分别高低**：

| # | 熵 | 问的问题 | 低熵的表现 | 高熵的表现 |
|---|---|---|---|---|
| 1 | **位置熵** | 哪些位置有信息？ | 绝大多数是零 | 每个位置都在贡献 |
| 2 | **值域熵** | 每个位置能取多少种值？ | 几个离散常量 | 连续分布，接近表示宽度 |
| 3 | **结构熵** | 整体能否被一个程序重构？ | 能，且程序很短 | 不能，只能逐位存 |

**这三种熵各不相同，「低熵」必须指明是哪一种。** 常见的一个错误推理是「位置稀疏 ⇒ 整个权重稀疏 ⇒ 压缩能省 600 倍」——位置稀疏只给出第 1 种熵，另外两种不跟着降。反过来，某个张量位置全密（第 1 种熵高）也可能值域只有两三个取值（第 2 种熵低）。

## 三、实测：同一个模型里的两种权重

这台机器的 46 层里，前 14 层是**编译**出来的（RISC-V 电路的权重），后 32 层是**训练**出来的（Qwen）。两者的三种熵对比：

| | 编译权重（blk.0–13） | 训练权重（blk.14–45） |
|---|---|---|
| **位置熵** | 非零率 **0.0568%**（层汇总 0.0021%–0.1094%） | 100% 稠密 |
| **值域熵** | **4.515 bit/权重**（1,086 个不同 bf16 位模式，幅值只有 672 个；bf16 的表示宽度是 16 bit） | **10.567 bit/权重**（用到 7,641/65,536 个位模式） |
| **结构熵** | 能——它由 `circuit/` 的电路定义生成 | 不能——没有生成它的程序 |
| **实际压缩** | **5.30 GiB → 8.30 MiB（653.7×，无损）** | bf16 → Q4_K，**−4×，有损** |
| **还能再压吗** | 能：CSR 再过 zstd 仍可 10.15×（端到端 6,633×）；更彻底是只存电路参数、加载时重跑编译（代价是几分钟） | **不能**，除非接受有损 |

**同一个文件、同一台机器：14 层压了 654 倍且逐个浮点都可复核，32 层压 4 倍就已经在丢精度。** 差别不在算法，在这两层是「算出来的」还是「学出来的」。

另一处需要注意的口径：**bf16 的 16 bit 是表示宽度，不是熵。** 训练权重的实测经验熵只有 10.567 bit——它只用到 65,536 个可能位模式里的 7,641 个。把表示宽度当熵，会高估训练权重的高熵程度约 1.5 倍。

另一个更极端的例子：chip token embedding 的 **394,164 行（3.38 GiB）** 被**826 字节**的 blob 取代——因为那 394,164 行也是程序生成的。这不是压缩，是**反编译**。

## 四、分布：不是单点数字，而是两个数量级的离散

三种熵在两类权重上的**分布**（数据口径见 `_k0v5/REPORT_ENTROPY.md`：chip 层取 `chip_sparse_tensors.npz` 的 84 个矩阵、1,615,758 个非零；Qwen 层取 `models/Qwen3.5-4B` 的 32 层 248 个 2D bf16 矩阵，7.14 GB）：

| 指标 | 类 | min | median | max |
|---|---|---|---|---|
| 非零率 % | chip 矩阵（75 个有效） | 0.0003 | 0.0195 | 0.4131 |
| 非零率 % | chip 层汇总（14） | 0.0021 | 0.0528 | 0.1094 |
| 非零率 % | Qwen（272 个矩阵） | 100 | 100 | 100 |
| 值域熵 bit/权重 | chip 矩阵 | 0 | 1.596 | 5.046 |
| 值域熵 bit/权重 | chip 层汇总 | 2.619 | 4.110 | 4.841 |
| 值域熵 bit/权重 | Qwen 矩阵 | 10.475 | 10.536 | 11.459 |
| 不同位模式数 | chip 矩阵 | 1 | 6 | 504 |
| 不同位模式数 | Qwen 矩阵 | 2,722 | 4,885 | 5,312 |
| zstd 值流 | chip 矩阵 | 0.57 | 26.75 | 348.8 |
| zstd 全流 | Qwen | 1.199 | 1.278 | 1.285 |

**同口径全局对照**：

| 指标 | chip（14 层） | Qwen（32 层） | 比值 |
|---|---|---|---|
| 非零率 | 0.0568% | 100% | **1,761×** |
| H_pos（bit/元素） | 0.0069 | 0（无稀疏性可测） | — |
| 值域熵（bit/权重） | 4.515 | 10.567 | **2.34×** |
| 不同位模式数 | 1,086 | 7,641 | 7.0× |
| zstd 值流 | 24.56× | 1.279× | 19.2× |
| zstd 全流（含稀疏化） | 653.7× | 1.279× | **511×** |

**三个要点**：

1. **最悬殊的是位置熵**——差了 1,761 倍（层汇总口径），矩阵级最大差到 0.0003% vs 100%。**那 653.7× 的压缩比几乎全部由这一维贡献**：稠密转 CSR 一步就到 653.7×，值域 zstd 只再贡献 24.6×。
2. **最不悬殊的是值域熵**——只有 2.34×。它足以区分两类权重，但不足以单独立判据（见 §七）。
3. **值域之外还藏着一点顺序冗余**：按纯符号频率，chip 的理论压缩上限是 16/4.515 = 3.54×，实测值流达 24.56×，是上限的 6.9 倍。差额来自值序列的顺序结构——同一行或相邻非零常是同一个常量，zstd 找到了长匹配。这属于结构熵的一部分，量级远小于位置维。

**分布形态**（9 等宽桶计数，详见 `_k0v5/REPORT_ENTROPY.md` §7）：chip 的值域熵**强左偏长尾**（54/75 个矩阵只用 1–2 种位模式，同时有少数矩阵用到 500 种）；Qwen 的值域熵**尖峰在左端**（219/272 落在 10.475–10.584 的窄带里）。位置熵方面 Qwen 退化成一点，没有分布可言。

**一个数据结构上的例外**：84 个 chip 矩阵里有 **9 个 nnz = 0**（`blk.7` 的 `attn_qkv_gate`/`ssm_out`/`ssm_beta_alpha`，以及 `blk.12`、`blk.13` 的同样三个 slot）——这些 slot 在该层由 full-attention 取代，电路里没有任何非零。它们的熵无定义，已从分布中剔除，所以矩阵级统计是 75 个而不是 84 个。

## 五、「有损」到底意味着什么

> **有损意味着存下来的是统计规律，而统计规律的熵就是它的信息量，压不下去。**

展开说：

1. 训练权拟合的不是数据，是**数据的分布**。分布是高维、连续、弥散的，没有哪几个权重专门承载「巴黎是法国首都」；这条知识摊在几十万个权重的微小扰动里。
2. **弥散 = 高熵**。信息不在位置上，而在整体模式里，所以删掉任何一处都在删信息。
3. **信息量就是下界**。把 `w` 无损压到接近 `H(w)` 之后就到底了（香农）。实测训练权重的经验熵是 10.567 bit，**所以无损压缩几乎拿不到东西**（实测 zstd 只有 1.279×）。
4. **越过 `H(w)` 只能有损**。Q4_K 把每个权重压到 ~4.5 bit，而实测信息量是 10.567 bit——差的那部分是真实的信息，不是冗余。它表现出来就是精度损失，不是「算法没调好」。

**推论**：对纯训练出来的权重，「把它变成低熵分布」这条路是关死的。**剪枝**必然有损（除非找到彩票假设里那个极小子网）、**量化**必然有损、**无损压缩**上限就是 `H(w)` 而已。

## 六、存储代价的定义

把上面几条合成一句可操作的话：

```
cost(w) ≈ |P(w)|
```

其中 `P(w)` 是**还原 w 所需的程序**。两种极限情形：

- **`P` 存在且很短**（编译权重）：`cost` 由 `|P|` 决定，与 `w` 的元素个数无关。删掉 `w` 里的一切、只留 `P`，**无损**。
- **`P` 不存在**（训练权重）：退化成 `cost = H(w)`，而 `H(w)` 是数据分布的信息量，**不可降低**。

**注意这不是「越稀疏越省」**：一个位置全密、但每个值都是 ±1 的张量，`P` 可以写成「全 1 加符号位」，`cost` 仍然极低。**决定代价的是 `P`，不是非零率。**

## 七、架构意义：把「确定的」搬到编译域

由此得到的判据只有一条：**这一层的行为是确定的，还是统计的？**

| 行为 | 例子 | 归哪 |
|---|---|---|
| **确定**——同一输入必得同一输出，且能用算法写出来 | 算术、地址计算、状态机、循环、精确比较 | **编译域**（低熵，能压 3 个数量级） |
| **统计**——同一输入要「看语料里的情况」 | 语言理解、常识、推理 | **训练域**（高熵，只能按信息量存） |

**这台机器正是这么划的**：blk.0–13 是一个 RISC-V CPU（确定的），blk.14–45 是 Qwen（统计的）。14 层能压 654 倍不是因为压缩算法好，是因为**它们本来就不该以权重形式存在**。

**所以「降低权重熵」的正确做法不是压缩，是划界。** 顺着这个思路看产业里的其他做法，它们其实是同一件事的不同侧面：

| 做法 | 把什么划出去了 | 代价放到了哪 |
|---|---|---|
| **MoE** | 让「每次前向用到的权重」变小 | 路由（熵搬到路由轴上） |
| **SSM / 线性注意力** | 让跨 token 的状态变低维 | 表达能力 |
| **编译进权重（本项目）** | 把确定性计算从权重里拿出来 | 编译期 |
| 量化 / 剪枝 | **没划出去**，是在训练域内部硬压 | 精度（有损） |

**注意前三种和第四种的区别**：前三种降低了「单位计算量触及的权重」，第四种降低的是「同一个权重的位数」。**只有前者是无损的。**

## 八、可检验判据

这个框架能反过来判断一个权重是编译的还是训练出来的。熵的分布数据（§四）把判据收紧成两条**强信号**加两条**辅助确认**：

**强信号（可独立成立）：**

1. **位置维能不能掉 3–4 个数量级**：非零率 ≤ 0.1%，或稠密流的 zstd ≥ 1000×。
2. **有没有一个能重跑出逐位相同权重的生成程序**（`circuit/` 这类源文件）。

**辅助确认（单独不可靠）：**

3. 值域熵（实测 4.5 vs 10.6）。**单独用它判会得出相反答案**：一个位置全密、值域只有 ±1 的张量，值域熵极低但位置熵极满，多半是训练初期或归零后的退化权重，不是编译权重。
4. 值流 zstd（24.6× vs 1.28×）。同理会漏判上面那种张量。

**判据的用处是发现架构问题**：如果某一层本该是确定的（比如某个固定算法），却被训练出来、且怎么压都压不动，说明**它被放错了域**。

## 九、边界与反例

**「低熵」不等于「可压」**。熵必须按**整体数据结构**算，不能按单个元素算：

chip 的 **21 个 code dim** 值域是 ±2⁻²⁰，本质上每个只有**一个符号位**，单看熵极低（1 bit）。但它们拼起来就是 token id 的 **21 bit**（5 位 family + 16 位 payload，见 [TOKEN-ENCODING](../design/TOKEN-ENCODING.md)）。**单元素熵低，整体信息密度满**——对它做任何压缩都会破坏 `code_token` 的读出。

**同理，位置稀疏只解决三种熵里的第一种**。这个项目的压缩比之所以是 654 而不是「几千」，就是因为它只降了位置熵：1,615,758 个非零仍然各占 2 字节 bf16，值域熵的 11.485 bit 冗余没动（`col` + `w` 各 3.2 MB）。**要再压就得做值域编码，而那是另一件事**——只是因为 8.30 MiB 已经不是瓶颈，所以没做。

**最后一类边界**：zstd 压缩比是**经验代理**，不是柯尔莫哥洛夫复杂度。它能给出「找不到短程序」的经验证据，无法证明「短程序不存在」——而后者正是该复杂度不可判定的地方。chip 层「有程序」这一事实来自 `circuit/` 的源文件，不是从 zstd 测出来的。

## 十、一句话收尾

> **训练权重的高熵不是实现缺陷，是「它在拟合一个高熵的分布」这件事的直接后果。**
> **能压下去的权重，一定是「本来就不该用权重表达」的东西。**
