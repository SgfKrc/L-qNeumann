# 确定与概率的分层：三种熵如何划开两类计算

> 面向「权重即计算」 · 基于同一模型内两类权重来源的实测 · 产出「该训练还是该编译」的判据

> 状态：**现行**
> 更新日期：2026-11-24
>
> 适用范围：本项目对「世界是确定的还是概率的」这个问题的立场，以及由它推出的判据；读者是想知道这个项目在哲学上到底主张什么的人。

## 一、一句话

**本项目不回答「世界是确定的还是概率的」——它只问「还原这段信息需要多复杂的程序」，而这个问法是可测的。**

## 二、为什么换问法

「确定 vs 概率」作为本体论问题，会把讨论拉进物理学（微观离散、宏观连续、量子测量）。本项目没有能力也不需要回答那一层——它手里只有一份文件、一台机器、两种来源的权重。

能测的只有一件事：`cost(w) ≈ |P(w)|`，**还原这个权重需要多复杂的程序**。于是「确定」和「概率」被重写成**观察者侧**的判据：

| | 存在短程序 `P` | 不存在短程序 |
|---|---|---|
| 这段信息的处境 | 可以用算法再生；删掉它、只留 `P`，**无损** | 只能以分布/样本的形式存；越过 `H(w)` 就是有损 |

**注意这个定义不问世界本体长什么样，只问一段给定观察能不能被更短地重述。** 这是它能绕开物理争论的原因。

## 三、绕开争论的关键一步：随机性 ≠ 不可压缩性

这是整个框架的支点，也最容易被混淆。四个格子把它们分开：

| 例子 | 结果随机吗 | 有短程序吗 |
|---|---|---|
| 抛 1000 次硬币，**只记统计量** | 是 | **有** ——「p=0.5 独立」一行字 |
| 抛 1000 次硬币，**记每一次的结果** | 是 | **没有** —— 1000 bit 就是全部内容 |
| 一段小说文本 | **不随机**（印在纸上） | **没有** —— 只能逐字存 |
| RISC-V 一条指令的语义 | 不随机 | **有** —— 几行代码 |

**所以「随机」与「不可压缩」是两个独立的轴。** 世界可以既概率又低熵——玻尔兹曼分布就是那个 `P`。量子力学说「测量结果是概率的」，讲的是**分布**；而**分布本身完全可以有短描述**。

这一步之后，「世界是概率的还是确定的」就不再是二选一：**概率描述的对象也可能有短程序，确定描述的对象也可能没有。**

## 四、本项目揭示了一个更精确的区分：两种「确定性」

[权重熵](WEIGHT-ENTROPY.md) §六 里写的判据是「**行为是确定的还是统计的**」。**这个判据不够精确**——因为 Qwen 那 32 层的行为**也是确定的**：同一输入逐位相同的输出，不抽签，它满足「同一输入必得同一输出」。

真正的区分在**结构**：

| | 行为确定 | 结构有短程序 |
|---|---|---|
| **chip 层（14 层）** | 是 | **是** —— 由 `circuit/` 的电路定义生成 |
| **Qwen 层（32 层）** | 是 | **否** —— 没有生成它的程序 |

**两者在物理上都不抛硬币，在信息学上差 155 倍**（5.30 GiB → 8.30 MiB 的 619× 无损 vs Q4_K 的 4× 有损）。

所以「确定性」有两种，必须分开说：

- **算法确定性**：存在一个人能写出来的 `P`（算术、地址计算、状态机）
- **函数确定性**：没有 `P`，但输入到输出是一个确定的映射（训练出来的网络）

## 五、概率论是「不可压缩性的微积分」

按上面的框架看，概率论与数理统计不是「关于随机性」的数学，而是「**关于没有短描述的东西如何被最优地处理**」的数学。

这解释了它为什么在第二类对象上无可替代：当 `P` 不存在时，唯一能做的就是估计分布、做期望、给置信区间。也解释了它为什么在第一类对象上效率极低：那里明明有 `P`，用统计去逼近等于用 `O(2^n)` 换 `O(n)`（见 [权重熵](WEIGHT-ENTROPY.md) §六）。

## 六、世界是分层的，而且这个分层可测

> **世界不是「确定的」或「概率的」，而是按「还原它所需的信息量」分层的。** 有些结构有短程序（物理定律、算术、语法），可以被算法再生；有些没有（一次具体的对话、一张具体的人脸），只能以分布逼近。

判据是经验性的、可操作的：**能无损压三个数量级的是第一层；压 4 倍就必须丢精度的是第二层。**

这正是「**划界**」成为核心动作、而不是「压缩」的原因：

- 若世界纯概率 → 拟合是唯一方法，划界没有意义
- 若世界纯确定 → 拟合是纯浪费，划界是显然的
- **机器学习之所以有效，恰因为世界是混合的**：大量可预测的规律落在「有短程序」那一侧，但逐个写成程序太贵，于是用统计去统一逼近

**本项目在这条逻辑上只多加了一句**：当某段规律的结构**已经被人类发现**（RV32 指令、算术、进位链），就应当把它从训练域搬出去写成程序。那 14 层能压 619 倍、能逐位反查，不是因为压缩算法好，而是因为**它们本来就不该以权重形式存在**。

## 七、边界：这套框架不能证明什么

柯尔莫哥洛夫复杂度**不可判定**。所以本项目能证明的只是「**我们目前没找到短程序**」，而不是「**短程序不存在**」。

Qwen 权重压到 4 bit 就失真，这是**经验事实**，不是数学证明。这条经验判据仍然可靠，理由是**量级**——619 与 4 差着 155 倍，不像「还没找到」，更像「确实没有」。但这是**统计性的信心，不是证明**，不能含糊。

同样地，本项目**不回答**：模型能力的极限、泛化从何而来、多少参数才够。它量的是权重的可压缩性，不是模型的能力上限。

## 八、一句话收尾

> **别问世界是确定的还是概率的，问这段信息有没有一个短程序；如果有，就把它写下来，而不是让统计去硬撑。**

本项目对世界本体的立场是**沉默的**——它只对「在它面前这份观测里，哪些部分能被更短地重述」有话说。这个位置很像统计力学刚出现时的位置：不争论本体，只给出一条能从观测里算出确定结论的路。
